# Fotos del equipo

Fotos tomadas de [mandocastudio.com/about-us](https://www.mandocastudio.com/about-us/). Se usan con fines académicos.

- **En WordPress:** al activar el tema (o con `wp mandoca seed`), las fotos de esta carpeta se suben solas a la Biblioteca de medios y quedan como foto de cada integrante. Para cambiar una: _Team → editar al integrante → Photo_ (imagen destacada). Cuadrada, 400×400 px o más.
- **Nombres de los archivos:** el tema busca la foto de cada integrante por su alias, con estos nombres exactos:

| Integrante | Archivo           |
| ---------- | ----------------- |
| JackRevon  | `jackrevon.webp`  |
| Jhonken099 | `jhonken099.webp` |
| Devz       | `devz.webp`       |
| CrimReaper | `crimreaper.webp` |
| Momoye     | `momoye.webp`     |

Si una foto falta, el sitio muestra las iniciales de la persona en su lugar.
